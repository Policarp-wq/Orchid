Rules this mockup assumes

  • Commands: start, stop, set BPM (30–240), set pulse. The PC rejects settings changes while recording; the phone shows them locked.
  • The phone sends the token in an Authorization header, not a cookie, so other web pages cannot fire commands at the PC.
  • Elapsed time is displayed from state sent by the PC. It is a display only, never used to timestamp notes.
  • Nothing about beats, ticks or key presses is shown on the phone.
